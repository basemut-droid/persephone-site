## HOW TO VERIFY AGAINST THE LIVE SITE

Three of the last four wrong conclusions in this project came from reading a **text
conversion** of a live page. Text conversion drops images, iframes, icons, and anything
carried by a class. It cannot answer a question about design.

So: when you need to know what the live site does, **fetch the raw HTML and read the
markup** — the `<img>`, `<iframe>`, `<svg>`, `<i class=…>` elements and their classes. If
raw HTML is not available to you, the answer is unknown and goes to `OPEN-QUESTIONS.md`.
Never infer the absence of a visual element from its absence in extracted text.
