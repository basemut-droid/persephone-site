`src/content/blog/de/`, and `src/content/site/de.json` held at the moment
this archive was made (NIGHT-RUN.md Phase 2), after Phase 1 restored the
content that had been silently lost during composition (the Angebote
self-recognition list, and the headings on Beratung/Workshops/Kontakt),
but before Phase 3 applied any of the owner's editorial corrections
(typos, the Selbsthilfegruppe intro choice, etc.).

**This directory is never rendered and never edited again.** It exists
so the original extraction survives even as `src/content/` is corrected
going forward — see the "Two kinds of fidelity" section this freeze is
based on, in `docs/external-review.md`'s recommendations, and the
updated rule in `CLAUDE.md`.

If you need to know exactly what a page said before any Phase 3 (or
later) correction, this is where to look — not `git log`, and not
`src/content/`, which is now the site's live, editable copy.
